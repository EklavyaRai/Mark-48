HOW TO USE THIS CONTACT PAGE

1. Put these 3 files in the same folder as your portfolio:
   - contact.html
   - contact.css
   - contact.js

2. In your existing portfolio HTML, find the "Contact Me" button/tab.

3. Change its link to:
   href="contact.html"

Example:
<a href="contact.html">Contact Me</a>

4. Open your main index.html in the browser and click Contact Me.
